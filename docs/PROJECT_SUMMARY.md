# 図面チェック・自動見積積算システム — プロジェクトサマリー

最終更新: 2026-06-11

## 1. 概要

建築図面（PDF/画像）をアップロードすると、AIが自動でチェックと積算を行うWebアプリ。

入力: 建築図面ファイル（PDF・PNG・JPG）
出力: チェック結果レポート（画面表示）＋ 見積書（Excel）

## 2. 主要な機能

- **図面チェック** — 記入漏れ・不整合・規格外項目を自動検出し重大度で分類
- **数量拾い** — 図面から面積・長さ・開口数などの数量を自動抽出
- **自動積算** — 抽出数量 × 単価マスター = 見積金額を自動計算
- **Excel出力** — 積算結果を見積書フォーマットで出力

## 3. システム構成

```
[ユーザー]
    ↓ 図面アップロード（PDF/PNG/JPG）
[Streamlit Web UI]
    ↓
[checker.py] ─── Claude Vision API ───→ チェック結果（JSON）
    ↓
[estimator.py] ── 数量 × 単価マスター ─→ 積算金額
    ↓
[Excel出力 / 画面表示]
```

## 4. 主要ファイル

| ファイル | 役割 |
|---|---|
| `src/app.py` | Streamlit メイン画面 |
| `src/checker.py` | 図面チェック（Claude API呼び出し） |
| `src/estimator.py` | 数量拾い・積算計算 |
| `src/price_master.py` | 単価マスターの読み込み・管理 |
| `data/price_master.csv` | 標準単価マスター |

## 5. 実行コマンド

```powershell
pip install -r requirements.txt
streamlit run src/app.py
```

## 6. 対応図面種別（想定）

- 平面図（間取り・寸法・室名）
- 立面図（外壁・開口部）
- 断面図（階高・軒高）
- 配置図（敷地・建物位置）

## 7. チェック項目（標準）

| カテゴリ | 項目 |
|---|---|
| 基本情報 | 図面名称・縮尺・作成日・設計者名 |
| 寸法 | 通り芯・開口寸法・室面積 |
| 室名 | 全室の名称記入 |
| 建具 | 建具記号・開き方向 |
| 法規確認 | 採光・換気計算の記入 |
